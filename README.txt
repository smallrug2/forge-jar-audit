Forge Mod Jar Auditor (jar_audit.py)
========================================
Coded by: Muse Spark (Meta AI assistant)

License: MIT (see LICENSE file)

WHAT IT DOES:
Audits a Minecraft Forge mods folder: lists every modId/version, flags missing mods.toml, duplicate modIds, and missing or out-of-range mandatory dependencies.

REQUIREMENTS:
Python 3.8+ only - no extra packages needed (stdlib only).

HOW TO RUN:
python jar_audit.py --help
python jar_audit.py --mods "C:\Minecraft\mods"

PLATFORM:
Windows + Linux + Mac: yes.
